# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in `@open-tomato/define-config`, **do not open a public issue**. Instead, report it privately using GitHub's private vulnerability reporting:

1. Visit the [Security Advisories](https://github.com/open-tomato/define-config/security/advisories/new) page
2. Click "Report a vulnerability"
3. Provide details about the vulnerability

All vulnerability reports are reviewed and addressed promptly in private before any public disclosure.

## Supported Versions

Only the latest minor release line (`0.x.*` where `x` is the highest released minor) receives security fixes. For example, if the current release is `0.5.1`, only the `0.5.x` line receives fixes; `0.4.x` and earlier are no longer supported.

When a new minor release is published, the previous minor line enters maintenance mode with no further updates.
